# Break room art

The original character, shadow, desk, table, computer, big table and cabinet
sprite sheets are from the community playground at https://bryllim.com/,
under `/images/game/`. Their filenames are preserved here, and the game serves
them locally rather than requesting them from the reference site at runtime.

Additional interactive furniture is drawn in `loungeRenderer.js` using the
same grayscale pixel style. Music and effects are synthesized locally by
`loungeAudio.js`; no audio streams or chat services are used.
